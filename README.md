# Furniro React Website

This project recreates the supplied Furniro Figma screenshots as a responsive React/Vite website.

## Requirements implemented
- React.js component-based implementation
- React Icons package (`react-icons`)
- Tailwind CSS dependency and Tailwind utility classes
- Array-driven repeated product/category/blog rendering with `.map()`
- React hooks (`useState`, `useEffect`, `useMemo`)
- Responsive desktop/mobile CSS
- Reusable Navbar, Footer, ProductCard, Benefits, PageHero and page components
- Functional cart quantity controls, cart drawer, product selection, filtering and navigation

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The supplied design reference is implemented across Home, Shop, Product, Cart, Checkout, Contact, Blog and Product Comparison views.
